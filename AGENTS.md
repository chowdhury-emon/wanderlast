# AGENTS.md

## Repo shape
- Two independent npm projects, no root `package.json` or workspace: `frontend/` (Next.js) and `backend/` (Express). Two lockfiles, two `node_modules`; install and run **inside each directory**.
- `frontend/` is the only git repo (nested `.git`, branch `main`, one commit, no remote). The root and `backend/` are untracked, so `git status` at the root fails - use `git -C frontend ...`. `backend/.gitignore` (`/node_modules`, `.env`) currently has no effect because `backend` is not in a repo.
- `frontend/components/` holds `Navbar.tsx` and `Hero.tsx`; routes live in `frontend/app/` (App Router, only route is `/`).

## Frontend (`frontend/`)
- Next.js 16.4.3 + React 19.3 - not the version in your training data. Read the bundled docs in `frontend/node_modules/next/dist/docs/` before using Next APIs; heed deprecations.
- Commands: `npm run dev` / `build` / `start` / `lint`. ESLint flat config only (no Prettier, no test script). Typecheck has no script: `npx tsc --noEmit`.
- `next.config.ts` enables `cacheComponents` and `partialPrefetching`, so caching/data-fetching semantics differ from older Next. See `docs/01-app/03-api-reference/05-config/01-next-config-js/cacheComponents.md` and `partialPrefetching.md`. Do not silently disable them to make an error disappear.
- Typed routes: `LayoutProps<"/">` and `PageProps<...>` are globals generated by Next into `.next/types` / `.next/dev/types` and pulled in by `next-env.d.ts`. They exist only after `next dev` or `next build` has run, and new routes need regeneration - run one of those before treating a missing-`LayoutProps` tsc error as real. `next-env.d.ts` is generated and gitignored: never edit it.
- Tailwind v4 is wired unusually: there is no `tailwind.config.*` or `postcss.config.*`. CSS is processed by `@tailwindcss/turbopack` via the `turbopack.rules` block in `next.config.ts`, and `app/globals.css` uses `@import "tailwindcss"` plus `@theme inline`. Don't add PostCSS/Tailwind configs or switch to `@tailwindcss/postcss`.
- Design tokens live in `app/globals.css` under `@theme inline`, not a config file: `--color-brand: #16a1c0` (use `bg-brand` / `text-brand`), `--font-display` (Jost) for headings, `--font-sans` (Inter) for UI. Both fonts come from `next/font/google` in `app/layout.tsx`, so a build downloads them (network required).
- Import alias `@/*` maps to the `frontend/` root (e.g. `@/components/foo`).
- `frontend/AGENTS.md` is rewritten by `next dev` (managed `nextjs-agent-rules` block). Keep the block, and commit it instead of deleting it to "clean up" the diff.

## Backend (`backend/`)
- ESM (`"type": "module"`), Express 5 + `cors` + `dotenv`. Not runnable yet: `src/server.js` is empty (0 bytes), `package.json` `main` points at a nonexistent `index.js`, there is no `dev`/`start` script, and `npm test` is a failing placeholder. Confirm intended entrypoint/port with the user before inventing one.
- `.env` is gitignored and does not exist; no example file. Load it with `dotenv` (already a dependency).

## Not present
- No CI, no pre-commit hooks, no formatter, no tests, and no lint setup for `backend`.
